# Neural Chameleons Project Website

This website presents the research paper "Neural Chameleons: Language Models Can Learn to Hide Their Thoughts from Unseen Activation Monitors."

### 📁 Files Structure

```
.
├── index.html                    # Main website file
├── static/
│   ├── css/                      # Stylesheets (from Nerfies)
│   ├── js/                       # JavaScript (from Nerfies)
│   ├── images/
│   │   ├── neural_chameleons_overview.pdf    # Main overview figure
│   │   └── example_generation.png            # Example generation figure
│   └── neural_chameleons_paper.pdf           # Full paper PDF
├── nerfies-template/             # Original template (preserved)
└── _ICLR__Self_Obfuscation/      # LaTeX source files

```
